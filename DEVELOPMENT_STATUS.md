### What was established

- Next.js 16 (App Router) + React 19 + TypeScript strict, Tailwind CSS 4.
- Brand tokens in `src/app/globals.css`: royal `#315C9B`, burnished gold `#B47745`, black
  `#111111`, white `#FFFFFF`, charcoal `#292D32`, light grey `#F4F5F7`, plus derived
  `royal-deep`, `royal-tint`, `gold-deep`, `gold-tint`.
- Typography: Montserrat (display) + Open Sans (body), self-hosted via `@fontsource-variable`,
  with fluid `clamp()` scales for display / h2 / h3 / lead.
- Layout primitives: `Container`, `Section` (tone + spacing), `SiteHeader`, `SiteFooter`.
- UI primitives: `Button` / `ButtonLink` / `ButtonAnchor`, `Card`, `Eyebrow`, `SectionHeading`.
- Brand motifs: `InterlockMark`, `Diamond`, `DivisionGrid`, `BlockField` — decorative only.
- `LogoLockup` — temporary text treatment, isolated for one-file replacement.
- Placeholder favicon set + Open Graph card, generated by committed scripts.
- Accessible foundations: skip link, visible focus rings, `prefers-reduced-motion` support,
  `aria-current` on navigation, sticky header with mobile disclosure panel.
- Environment configuration guidance: `.env.example` (names and placeholders only),
  `.gitignore` protecting `.env*` while allowing `.env.example`.

**Defect found and fixed in Stage 1:** the initial `eslint.config.mjs` used `FlatCompat` with
`eslint-config-next`, which throws `Converting circular structure to JSON` under ESLint 9.39.
Because `eslint-config-next` v16 ships native flat configs, the `FlatCompat` shim was removed and
the configs are spread directly. A second error — `react-hooks/set-state-in-effect` when the
mobile menu closed itself on route change — was fixed by closing the panel in the link click
handlers instead of an effect.
