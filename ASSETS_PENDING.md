### What is in the site right now

`src/components/brand/LogoLockup.tsx` renders a **type-only business lockup**:

```
OBSIDIXZ
REAL ESTATE
```

set in Montserrat Bold with wide tracking, beside a small outlined-square/gold-square marker.
The marker is decoration, marked `aria-hidden`, and is **not** the Obsidixz emblem.

This is permitted by the brand rules ("a business lockup such as OBSIDIXZ REAL ESTATE may be
used"), and no attempt has been made to redraw, rotate, distort or recolour the parent logo.

### What to supply

Into `public/brand/`:

```
public/brand/obsidixz-wordmark-light.svg     # for light backgrounds
public/brand/obsidixz-wordmark-dark.svg      # for dark backgrounds (white wordmark)
public/brand/obsidixz-emblem-light.svg
public/brand/obsidixz-emblem-dark.svg
```

SVG strongly preferred. If only PNG is available, supply transparent PNG at at least 3× the
largest display size (header lockup displays at roughly 150×40 CSS px, so 450×120 minimum).

### Where to change it

One file: `src/components/brand/LogoLockup.tsx`. Replace the placeholder marker `<span>` with the
supplied emblem `<Image>` (or inline SVG) and keep the existing `tone` prop driving which
variant is used. The header, footer, mobile panel and any page-level lockup all consume this
component, so the swap is single-point.

Also replace, once art is available:

- `public/favicon.svg`, `public/favicon-32.png`, `public/apple-touch-icon.png` — currently a
  neutral royal/white/gold geometric tile, generated by `scripts/generate-favicons.mjs`.
- `public/og-image.png` — currently palette + motif + typographic headline, generated by
  `scripts/generate-og-image.sh`.

## 2. Font licence

licensed under the **SIL Open Font License 1.1**, which permits web embedding and commercial use.
The licence files ship inside `node_modules/@fontsource-variable/*/LICENSE`.

No licence action is required. Recorded here so the position is auditable.
